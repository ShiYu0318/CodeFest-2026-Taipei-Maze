# 最近設施與全螢幕導引

更新日期：2026-11-08

## 使用流程

起點／終點欄下方常駐「最近設施」按鈕：廁所、電梯、服務臺、飲水處與哺集乳室。已有起點時，依步行路網找可達的最近設施，設為目的地後開啟導引。距離是圖面相對單位，不是實測公尺；不以直線距離替代不可通行的路線。

沒有起點時，在城市通內先呼叫 `qr_code_scan`。掃碼成功後，使用本次 QR Code 的位置搜尋，保留無障礙、排除通行類型與停用連接設施的限制。取消、逾時、等待舊回覆等掃碼失敗不選取目的地，提示實際掃碼狀態。一般瀏覽器無原生掃碼時顯示城市通提示；仍可搜尋並手動選取起點，再點選最近設施。

「帶我去」、選取終點或成功掃描定位，皆進入全螢幕導引。已規劃路線時顯示大箭頭、步驟文字、途經點，以及上一步／下一步；地圖與全螢幕畫面共用步驟索引，切換步驟會同步樓層及地圖焦點。「查看地圖」關閉導引並保留行程，路線區提供重新開啟大箭頭的入口。重新掃碼時暫時隱藏舊箭頭，成功定位後重算路線、回到第一步。

沒有目的地時提示選取終點；缺少起點、無可用路線或已抵達時顯示對應狀態，不捏造方向。上一步／下一步只是查看指示，不會宣稱使用者已到達，也不會更新 QR 定位時間。

## 方向、排版與可及性

- 箭頭表示地圖北向朝上的路段方位；QR Code 不提供手機面向，不可解讀為即時向左／向右轉。畫面保留對照地圖與現場標示的提示。
- 跨樓層步驟顯示上／下樓方向及設施種類。到達目的地的最後一步顯示勾號。
- 全螢幕採原生 `dialog`，支援 Escape、鍵盤焦點循環、關閉後返回地圖焦點，背景介面不接受操作。
- 預設／兒童／長輩模式共用可換行的按鈕與步驟；窄螢幕將箭頭與文字改為上下排列，保留字級與點擊高度。導引內容可垂直捲動，適應注音與放大文字。
- 步驟切換有短暫文字淡入及箭頭旋轉；遵守系統「減少動態效果」。七語文字隨程式打包，不使用執行時翻譯服務。

## 驗證與限制

自動測試涵蓋定位前的設施入口、成功／取消／失敗掃碼、以新 QR 位置搜尋、硬性路線限制傳遞，以及真實 Vue 元件在無路線、掃描中、路線首步與抵達步驟的輸出。另執行 ESLint、七語與 QR／路網資產驗證、正式建置。

路網仍是既有圖面模型，部分點位不在可規劃路網中；缺少連線或無障礙資訊時拒絕規劃，不保證整個臺北車站皆可導航。最近設施為圖面模型上的可達結果，未代表營運中或現場最短安全路線。
