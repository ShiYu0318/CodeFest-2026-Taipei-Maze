# 定位資訊與手動完成行程

**Goal:** 保留真實定位記錄，讓使用者在最後一步明確確認抵達並結束行程。

**Architecture:** 位置仍由既有 QR／URL controller 擁有；手動抵達是本頁的獨立確認記錄，不改寫 position、source 或 QR 時間。確認以起點、終點、限制及定位 revision 的行程鍵綁定；換起終點、重新定位或修改條件會失效。

**Constraints:** 不修改 TownPass，不新增依賴；七語、易讀模式及無障礙硬性過濾維持。

- [x] 「全部」顯示當層所有點位及原有圖示，導航路線仍保留。
- [x] `trip-progress.mjs` 提供純函式：行程鍵、最後一步手動確認、確認記錄有效性、位置來源／時間分類。
- [x] 單元測試涵蓋舊行程鍵、未到最後一步、無路線、QR／URL／手動／Demo 來源；不修改輸入定位。
