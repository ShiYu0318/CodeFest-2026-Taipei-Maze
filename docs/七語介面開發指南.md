# 七語介面開發指南

對應競賽主題「看不懂」：外籍人士與數位素養不足的人，可以用自己熟悉的語言操作站內導航。

## 現況

- 支援語言：繁體中文、English、Tiếng Việt、Bahasa Indonesia、ไทย、한국어、日本語（`id` 是印尼文，不是印地文）。
- 翻譯檔：`app/src/i18n/messages/<locale>.mjs`，與 App 一起打包，可離線使用；執行時不呼叫任何翻譯服務。
- 預設語言：依瀏覽器語言判斷（舊代碼 `in` 也視為印尼文），對不到時用繁中。使用者手動選擇後存在 localStorage（`taipei-maze.locale.v1`），優先於瀏覽器設定。
- 語言切換：位在各頁工具列，以「地球圖示＋短代碼」顯示；展開後的選單用各語言的原生名稱。
- 同步更新：`<html lang>`、原生 AppBar 顯示的 `document.title`、日期時間格式、小幫手的語音辨識語言。
- 設施名稱：繁中以外的語言，顯示「翻譯後的種類＋現場代碼」，例如 `Elevator 4`、`Floor access M3/M8`。清單與目前位置另外附上現場中文名稱，方便對照站內指標（`app/src/i18n/places.mjs`）。
- 注音：只在繁中的兒童模式顯示。
- 名稱搜尋：審查過的搜尋詞典只有繁中和英文；詞典完全不認得時，退回小幫手的七語設施名稱辨識（`app/src/search/fallback.mjs`），所以越南文、泰文、韓文、日文、印尼文也能用「廁所」這類詞搜尋。
- 「原始碼與授權」頁：說明文字已翻成七語，AGPL 聲明保留英文原文；政府資料授權條款在繁中顯示官方名稱，其他語言顯示譯名，連結都指向官方頁面。
- 「給站務人員看」卡片（`app/src/staff/staff-card.mjs`、`StaffCard.vue`）：選好目的地後出現。卡片上半部永遠是繁中大字，例如「請問『現場名稱』怎麼走？」；開了無障礙會多一句不能走樓梯；外籍使用者另外說明「我不太會說中文」。下半部用使用者的語言對照同一段話。深色模式下，卡片仍維持白底黑字，像一張印出來的告示。

## 新增或修改文字

1. 先在 `zh-TW.mjs` 新增 key，它是基準翻譯檔。
2. 其餘六個語言檔都要加上同一個 key，`{placeholder}` 也要一致。
3. 元件裡用 `const { t } = useI18n()`，再寫 `t("key", { name })`。
4. 要加注音的文字寫成 `<ZhuyinText :text="t('key')" />`；`tests/zhuyin.test.mjs` 會檢查這些繁中文字是否都有注音讀音。
5. 執行 `npm test`：`tests/i18n.test.mjs` 會確認七語的 key 與佔位符完全一致。
