## 資格與報名流程

### 隊伍與資料

- 每隊至少 4 人、至多 5 人，每人只能加入一隊；指定 2 人擔任主要及次要聯絡人。
- 年齡、身分與國籍原則上不限；報名時未滿 18 歲須有法定代理人書面同意。
- 未成年者與法定代理人共同參賽時，依表單勾選並於備註註明代理人姓名。
- 外籍參賽者依 FAQ 須提供居留證正反面影本，居留時間須大於 2026/11/8，並自行確認入境及簽證規定。
- 每名隊員需上傳簡歷，說明角色、技術專長、過往開發經驗或得獎紀錄；另提交姓名、聯絡方式等完整資料。
- 活動全程免費，不區分學生組及社會組。

### 審查與錄取

1. 透過官網填寫報名表，確認收到系統信。系統信代表資料已提交，仍須通過資格審查並完成必要補件。
2. 第一階段為書面審核，依報名資料及團隊背景審查；10/15 公告工作坊入選名單。
3. 每隊指派 1–2 人實體出席工作坊，其餘成員可線上參與；同日進行第二階段面談。
4. 綜合書審、出席與面談結果決定正式競賽資格；10/27 公告正取 40 隊及備取 4 隊。
5. 留意隊長信箱的行前通知，備取遞補由主辦單位另行通知。

正式參賽規模以 40 隊或 200 人為原則；另有「報名達 600 人或 150 隊即提前截止」的收件上限，兩者意義不同。主辦單位保留調整報名時間、隊伍數及遞補安排的權利。報名資料或隊員異動，FAQ 要求於報名截止前來信依指示修正。

## 現場報到與生活安排

### 報到與出席

- 全體隊員須實體到場並完成報到，攜帶政府核發的身分證明，如身分證、健保卡、駕照、護照或居留證。
- **報到使用 10/27 最終名單上的參賽編號，不是原報名編號。** [直接查看官方名單圖片](https://codefest.taipei/2026-fall/images/news/news-2026-2-1.jpg)。
- 未指派代表參加工作坊會取消資格；工作坊報到截止後 30 分鐘仍未完成報到，主辦單位得視情況取消資格；面談唱名三次未到會取消面試與競賽資格。
- 競賽報到截止後 30 分鐘仍未報到，主辦單位得取消個人及所屬團隊資格。就醫、其他重大事件等須提供證明並經主辦單位認定；面試與其他競賽不列入該重大事件例外。
- FAQ 說明 11/8 評審階段須全程在場，其餘時間可依隊伍需求安排；這不免除全員實體報到義務。
- 無故缺席會影響往後類似競賽的報名資格。參賽者並應配合問卷與訪問。

## 作品方向與開發規範

### 題目與成果定位

以「市政服務開源」為方向，基於台北通開發城市通微服務新功能。主題概略方向原則上於工作坊說明，正式內容於競賽當天公布，實際依主辦安排。官網公開規則未列出本次正式題目清單，應依當天公布的題目開發。

### 資料與第三方依賴

- 核心、關鍵資料須為公開且合法的開放資料，註明引用來源；只有其餘非必要資料可用模擬資料替代。
- 作品僅得使用開源軟體或套件。規則限制可能產生後續授權費、訂閱費、付費功能或影響上架的商用模組及第三方套件，並以 Google Maps 等商用地圖套件為例。
- 最終成果必須可移轉、可維運、可上架；違規可能扣分或取消資格。
- 不得抄襲、仿冒或侵害他人權益。依規則經訴訟程序確認屬實時，可取消參賽或得獎資格並追回獎金。

**備賽建議：**逐項整理資料來源、更新頻率、授權、套件與服務依賴；不要只因目前有免費額度，就視為符合競賽的開源與移轉要求。涉及外部代管服務或授權適用疑義時，先向主辦確認。

### 官方建議技能與分工

| 領域 | 技術或職責 |
| --- | --- |
| 共通工具 | Git、Docker、Postman |
| 前端 | HTML、CSS、JavaScript、Vue、package.json 所列工具；畫面及 API 串接 |
| 後端 | Spring Framework、Hibernate、Tomcat；API 與資料庫串接 |
| 行動端 | Flutter、Dart、狀態管理、Widgets、網路通信 |
| 資料工程 | 彙整資料、資料源串接、系統架構 |
| 專案規劃 | 題目、應用場景、說明文字與市政服務需求 |

上述是官方建議能力與角色，規則未將此表列為每隊必須使用全部技術的清單。城市通官方另提供 Flutter App 與 Vue 3 微服務程式庫，可依作品整合方式查閱。

## AI 與 LLM 使用規範

規則區分「開發過程使用 AI」與「作品執行時提供 AI 功能」，選架構前必須先核對。

| 情境 | 官方規定 |
| --- | --- |
| 開發時使用 ChatGPT、Claude、Gemini、Codex 等 | 可協助企劃、寫程式、除錯、資料整理、模型訓練、微調、量化與轉換 |
| 預先用雲端 AI 產生文字、圖片或程式碼 | 可以使用，但固定內容不得宣稱為作品執行時的即時 AI 功能 |
| 作品執行時進行 LLM 理解、推論、內容生成 | 推論程序必須完全在裝置端執行 |
| 呼叫外部雲端模型 API | 作品執行時的 LLM 功能禁止使用 |
| 自架遠端模型伺服器、其他遠端 LLM 推論 | 同樣禁止；自行架設不構成例外 |
| 一般帳號登入、資料庫、檔案儲存、排行榜、資料同步 | 不受上述遠端 LLM 限制，但不得把使用者輸入或作品資料送到後端做 LLM 推論 |
| 模型資訊揭露 | 須列出模型名稱、版本、量化格式、推論框架及模型來源 |
| 現場驗證 | 評審可要求關閉 Wi-Fi 與行動網路，以全新題目驗證 LLM 功能 |
| 裝置端 AI 工具及模型來源 | 不得為規則所稱「危害國家資通安全產品」，包含大陸廠牌資通訊軟體、硬體與服務 |

**備賽建議：**模型、權重與推論依賴事先存好；在實際展示裝置上測試斷網推論、全新輸入、記憶體占用與延遲。若以筆電充當遠端伺服器，再由手機呼叫，不能自行認定為合規的「裝置端」。官方未在公開規則詳細界定所有裝置拓樸，應先向主辦確認。

來源：[競賽規則伍第二款第四目](https://codefest.taipei/2026-fall/rules/)、[技術 FAQ](https://codefest.taipei/2026-fall/rules/faq/)。

## 成果發表與評分

### 發表要求

- 第 2 天進行初選與決選；放棄成果發表即喪失評選資格。入圍隊伍須參加決選。
- 初選約 2 分鐘；決選約 5 分鐘，並進行問答。公開規則未另外載明問答秒數。
- 只能投影成果實際運作畫面，**禁止使用任何形式簡報**，包含 PowerPoint、Keynote、Google 簡報等。
- 官方建議說明題目、想法來源、應用場景、開發項目、資料來源、技術細節，並實際展示作品運作。
- 詳細發表程序與規則由工作坊公布，現場順序與操作方式仍需核對行前通知。

### 初選共 100 分

| 項目 | 配分 | 重點 |
| --- | ---: | --- |
| 服務應用 | 40 | 想法有創意且符合題目 |
| 視覺呈現 | 30 | 功能介面清楚、美觀 |
| 技術完整度 | 30 | 架構清楚、資料來源正確、功能運行流暢 |

### 決選共 100 分

| 項目 | 配分 | 重點 |
| --- | ---: | --- |
| 服務應用 | 25 | 情境完整、實用 |
| 服務完整度 | 30 | 服務落地可能性及難易度 |
| 技術穩定度 | 20 | 操作流暢與系統穩定 |
| 視覺呈現 | 15 | 操作介面與功能完整度 |
| 創意及公益性 | 10 | 活用開源、公共利益、作品創意、發表完整順暢 |

各階段由評審依配分評分後轉換成序位，再合計序位決定晉級或名次；決選序位相同由評審共識決定。不是只將所有評審原始分數平均後排序。獎項可從缺或並列。官網評審介紹目前未啟用，因此本文件不將頁面程式中的預載姓名視為正式公告名單。

### 備賽建議的展示分配

初選可用約 20 秒說明使用者與痛點、80 秒操作最重要的服務流程、20 秒交代資料與技術亮點。決選可用約 40 秒說明情境、3 分鐘實機展示、50 秒交代架構與落地方式、30 秒收尾。這些是練習建議，並非官方規定；問答時間另依現場安排。

### 得獎後的必要流程

1. 主辦單位於賽後 2 週內，以 Email 通知希望協作的項目，並將隊伍聯絡方式提供給相關開發人員。
2. 自通知日翌日起算 1 個月內，將指定作品元素整併到官方程式庫。若經主辦認定整併困難或不適合整併，得不受此限。
3. 協作範圍限競賽期間完成的作品，主辦僅要求簡易修改或刪減，不要求額外新功能；有困難應盡速提出調整與協助需求。
4. 在指定期間以書面提供團隊決定的獎金分配方式及本國銀行匯款帳號。
5. 完成協作後，依規則於 30 日內匯入指定帳戶；每位得獎者依相關規定辦理扣繳。
6. 配合主辦要求，在往後黑客松競賽前分享經驗。

未依限提供分配或帳號，主辦可平均分配、暫保留或依法處理。整併時如發現使用第三方商用服務、未配合上傳或修改指定專案，或其他主辦認定情形，可能撤銷獎項或不發全部／部分獎金。

## 開源授權與其他權利義務

### 全體參賽隊伍

- 公開釋出所有本競賽開發成果，確保擁有著作權或完整合法授權。
- 依規則以 AGPL 條款授權開發成果，附上指定授權聲明，包含程式說明、著作權年份與作者，以及 AGPL 第 3 版或後續版本的條款告知。
- 規則另載：以無償且不可撤銷條件授權主辦及其所屬機關，授權期間自公布得獎結果日起算 1 年，期間不得下架成果。這是競賽條文摘要，不代表可將 AGPL 本身理解成只有一年效力。
- 提案、圖文、影音及其他資料，也須確保不侵害他人權利或違法。
- 參賽提供的圖文、照片、影音與活動拍攝內容，含姓名及肖像等，依規則永久、無償、不可撤銷且不限區域，授權主辦、協辦與其授權第三人作非營利宣傳使用；不另行通知。

### 得獎隊伍額外義務

全體成員另以永久、無償、不可撤銷、非專屬且不限區域方式，授權主辦使用開發成果相關智慧財產權，配合整合城市通開源程式碼；如整合需改作或編輯，須無償配合，衍生著作同樣授權。

### 其他條款

主辦保留修正、異動、暫停、取消及最終解釋權。爭議依中華民國法律處理，以臺灣臺北地方法院為第一審管轄法院。授權聲明應以官方原文製作，疑義向主辦確認。

來源：[競賽規則捌至壹拾](https://codefest.taipei/2026-fall/rules/)、[下載版活動須知第 9–10 頁](https://url.taipei/sJ6m)。
