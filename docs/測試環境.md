## 常用命令

在作品 repo 執行：

```bash
bash scripts/townpass-env.sh paths
bash scripts/townpass-env.sh doctor
bash scripts/townpass-env.sh deps
bash scripts/townpass-env.sh analyze
bash scripts/townpass-env.sh test
bash scripts/townpass-env.sh build-ios
```

開一個 Terminal 保持新版地圖的 Vue 開發伺服器運行；已在執行時不要重複啟動：

```bash
cd app
npm ci --registry=https://registry.npmjs.org
npm run serve -- --host 127.0.0.1 --port 8082
```

目前 App 的「CodeFest 測試環境」入口已指向 `http://127.0.0.1:8082/station-map`。修改 Vue 檔案後由開發伺服器提供 HMR；若 WebView 沒更新，退出該服務再進入。HMR 連線在 App 內仍待人工確認。修改 Dart／原生外掛則需依變更重啟或重建宿主。

另一個 Terminal 查看裝置後執行：

```bash
xcrun simctl list devices available
bash scripts/townpass-env.sh run-ios 828B0E1B-73C5-485E-A482-4C1A615B700B
```

若模擬器尚未啟動，先執行 `xcrun simctl boot 828B0E1B-73C5-485E-A482-4C1A615B700B`；已開機時不必重複。App 內依序進入城市服務 → 我的服務「更多」→「城市生活」分類，開啟「CodeFest 測試環境」，即可載入新版地圖。App 內畫面與 HMR 仍待人工驗證；網頁 HTTP 成功不代表 bridge 成功。掃碼需另用真機驗證。

獨立橋接診斷頁仍可用 `bash scripts/townpass-env.sh serve` 啟動於 `http://127.0.0.1:8765/`。若要在宿主測診斷按鈕，需暫時把 destinationUrl 改回該網址並重啟；目前地圖入口不會自動顯示診斷頁。

需另指定 checkout 時，以 `TOWNPASS_DIR=/absolute/path/TownPass` 執行 helper。路徑以參數安全傳遞，不把整個上游或本機 SDK 複製到作品 repo。

## 在另一台機器重建

先具備 Xcode、iOS Simulator runtime、Node.js、FVM、CocoaPods，再於作品 repo 的相鄰位置建立宿主：

```bash
git clone https://github.com/taipei-doit/TownPass.git ../TownPass
git -C ../TownPass switch -c work/codefest-test-env c8e5d4d3f8f699f3d9d6cd68e129ed4da12037b3
git -C ../TownPass apply --check "$PWD/integration/townpass/test-env.patch"
git -C ../TownPass apply "$PWD/integration/townpass/test-env.patch"
(cd ../TownPass && fvm install && fvm use 3.47.6 --skip-pub-get --skip-setup)
bash scripts/townpass-env.sh deps
bash scripts/townpass-env.sh build-ios --no-pub
```

以上 clone 命令只供不存在的目錄使用，既有 checkout 應先檢查工作目錄與版本；不要重複套 patch。另一台機器的 Simulator ID 不同，請用 `xcrun simctl list devices available` 選擇實際 ID。

## 來源與限制

Flutter／Dart 使用官方 GitHub、Google storage 及 pub.dev，沒有設定中國鏡像；FVM 來源依其官方安裝文件。上游套件依 lockfile 解析並保留原授權，這不是對整個上游依賴樹的最終非中國來源發行稽核。產品正式採用的依賴仍依 THIRD_PARTY_NOTICES 及 SPEC 審查。

SDK、runtime、cache、私有本機 log 與 build 產物不提交。Homebrew 安裝 FVM 時觸發其預設未使用舊版本清理；後續 Homebrew 安裝應設 `HOMEBREW_NO_AUTO_UPDATE=1`、`HOMEBREW_NO_INSTALL_CLEANUP=1` 避免額外維護動作。

Android SDK 官方要求接受授權；未取得同意前不代為接受。Apple 本機 Xcode first-launch 檢查已通過；iOS 簽章與實機安裝另依裝置及開發者帳號處理。
