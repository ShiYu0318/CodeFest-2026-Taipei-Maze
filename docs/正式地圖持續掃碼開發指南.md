# 正式地圖持續掃碼開發指南

本輪依使用者要求，把目的地／搜尋／通行條件／簡明模式／持續掃碼／抵達確認整合到 `/station-map`，保留隊友的樓層、縮放、拖曳、設施圖示與顯示設定。隊友另恢復的 `/navigation-demo` 仍是合成路網開發工具；正式地圖不靠它定位，也不將合成路線搬到北車座標上。

## 順暢的單一流程

1. 在正式地圖選終點：可用設施清單、在地圖選標點後設為終點，或展開七語詞典搜尋。搜尋先選實際設施再套用；限制只會增加，不會默默解除原有避樓梯條件。
2. 視需要勾「只參考無階梯連結」。尚無定位也能先設定終點。
3. 點「開啟相機，持續更新位置」。新版城市通顯示單一相機，下方保留終點、上次掃碼位置及提示。
4. 每次有效定位碼只更新自己的位置、重新計算已知樓層關係，終點與通行條件不變。無效碼、分享 URL、合成場景 QR 不改變本地圖的起點。
5. 地圖跟隨最後有效掃碼點的樓層與標點；綠色外框代表上次掃碼位置，金色外框代表終點。手動瀏覽／選取其他樓層不會改變定位。
6. 可排除提示中的不可用設備；已知關係中沒有符合條件者就顯示無可用連結，不以樓梯或未知設備替代。
7. 只有掃到與終點相同的 point ID，才顯示「確認已抵達」。由使用者比對現場名稱／樓層並明確確認，不能憑同區域／同樓層自動抵達；舊 QR 的抵達按鈕不能作用於新定位。
8. 收起相機後保留最後定位與終點；「結束這次導航」清除本次任務。簡明模式收起選配控制與連結清單；深淺色與兒童／長者設定沿用隊友配置。

浮動聊天同樣沿用顯示主題，並依 visualViewport 調整面板，避免手機鍵盤遮住輸入區。畫面／實機可用性仍需人工驗證，不能由 Vue build 判定全部通過。

## 現有資料的能力邊界

正式站圖是 89 個設施點與 19 條樓層連接關係，**不是已現地驗證的完整步行 Graph**。本輪只提供 zone／connector overview：

- 不捏造同樓層走廊邊，不計算不存在的距離／最快路線／轉彎方向，不承諾未知區域可達。
- 只採 `direction: bidirectional`、端點／樓層／zone 符合的連結；排除 `inferred`、`unverified`。
- 無階梯只採 `type: elevator` 且 `wheelchairAccessible: true`，再排除本次不可用設備；混合樓梯／電扶梯不符合無階梯限制。
- 同 zone 只代表同區域，不代表抵達，也不提供未經證實的走廊指示。
- 完整的「最快／最易懂」逐步導航仍需要實際走廊、轉彎、地標、可及性、設備可用性及現地核對；不以合成 demo 通過當正式北車路線已驗收。
- 真實集合等候區尚無 approved whitelist；不擅自把每個設施點都變成合法、安全的集合等候區。現有合成分享卡不推測映射到正式點。

## QR 契約

正式地圖使用獨立的 **preview** namespace，避免與合成圖混用：

```json
{"type":"taipei_maze_anchor","v":1,"site_id":"taipei-main-map-preview","graph_major":1,"anchor_id":"station_b1-e4"}
```

`station_` 後方是本地 `station-points.json` 的穩定 point ID；碼內不帶座標、樓層、朋友位置或要執行的 URL。僅接受相容版本、本地存在且未停用的點，最多 1024 UTF-8 bytes。手機朝向無法由此 QR 判斷。

這些碼是開發測試用，**尚未現地布設／核准**。掃描測試表只能驗證資料與狀態流程，不能證明人真的在車站該處。正式部署需凍結資料包與版本、審核座標／標牌位置、取得設置授權並現地驗證。

## 可列印的 89 個測試碼

`tools/generate-station-qr.py` 使用實際 production payload 函式，避免手寫測試資料與程式不一致。建置工具採 Lincoln Loop `python-qrcode` 8.2，BSD-3-Clause、固定 wheel hash；只在 `.local` virtualenv 生成 SVG，不加入手機／網頁 runtime。

```bash
python3 -m venv .local/qr-tools
.local/qr-tools/bin/python -m pip --isolated install --no-user \
  --index-url https://pypi.org/simple --require-hashes --no-deps \
  -r tools/requirements/station-qr.txt
.local/qr-tools/bin/python tools/generate-station-qr.py
```

產物：`.local/station-qr/index.html`（列印表）、`catalog.json`（對應 payload）、89 個 SVG。開啟 HTML，用另一台真機掃畫面或紙張；iOS Simulator 沒有實體相機，不能完成這項驗收。

## 測試與交付

- `npm test --prefix app`、`npm run lint --prefix app`、`npm run build --prefix app`。
- `bash scripts/townpass-env.sh build-ios --no-pub` 會重建包含最新正式地圖的 App 網頁包。
- Android PR CI 會建立最新網頁包與 APK，並保存 `townpass-debug-apk` artifact 7 天供手機測試。不包含模型權重或簽章私鑰。
- 模型安裝與本地語音見 [手機聊天與語音開發指南](./手機聊天與語音開發指南.md)。聊天不能直接更改導航定位或路線。

尚待人工實測：有效碼 A→B→A 持續掃描、相同碼重讀、錯碼不中斷、掃新碼同時點舊抵達、權限拒絕／背景／返回、手機鍵盤與讀屏、真實走廊與無障礙場勘。測試完成前保持 not_run。
