# 正式地圖掃碼定位開發指南

2026-11-07 最新使用者決策：指南針先跳過；QR 僅帶點位 JSON。正式地圖按「掃描定位」開啟 TownPass 既有單次原生相機，App 回傳原始字串，由網頁驗證及更新位置。這覆寫本文件前版「必須先選終點、再啟動自訂持續掃碼」的入口；原有合成導航與持續掃描模組保留供獨立測試。

## 操作流程

1. `/station-map` 沒有 point 時是瀏覽模式，不顯示目前位置；可自由切樓層及選取設施。
2. 按「掃描定位」，以 `flutterObject.postMessage(JSON.stringify({name: "qr_code_scan", data: null}))` 開啟原生掃碼。網頁先監聽回覆，等待期間鎖住按鈕。沒有 flutterObject 的瀏覽器會明示需由城市通開啟。
3. App 掃到 QR 後關閉掃碼頁，回傳 `{name: "qr_code_scan", data: "<QR 原始文字>"}` 的 JSON 字串。data 為 null 是取消；不假設原生會自動開網址。
4. 網頁驗證點位 JSON、場域及版本後，更新當前頁的 `?point=b1-e4&v=1`，不重載整個 WebView。自動切樓層、放大聚焦該點並顯示點位名稱及「您在這裡」。
5. 進入導航模式後，再選目的地，可使用清單、已選標點或七語詞典原型搜尋；保留無階梯、設備排除等硬性條件。
6. 再按「重新掃描定位」更新起點，目的地與限制保留。點選其他設施、看步驟或手動切樓層都不改寫起點。
7. 「退出導航，返回瀏覽模式」清除起點與目的地、移除 point／v，保留其他 query 及 hash。

## 網址參數與來源

`http://home.yoyo899843.com:8000/station-map?point=b1-e4&v=1` 是可直接開啟的定位入口；網址參數不是 QR 的內容。point 使用現有 station-points.json 的 ID，省略 v 視為 1；空值、重複 point／v、其他版本、停用或未知 ID 都拒絕，回瀏覽模式並顯示提示。

- 真正原生掃碼：position.source 為 qr，保存實際回覆處理時間 confirmedAt。
- 直接網址／重新整理：source 為 url、confirmedAt 為 null，顯示「由定位連結帶入，請核對現場位置」。不能把開頁時間當成掃碼時間。
- Vue Router 的自身參數同步保留當次 QR 來源與時間；上一頁／下一頁與同頁 query 變更重新套用該入口。
- 「您在這裡」代表最後定位碼或連結提供的點位，不會隨走動自動更新，也不是 GPS、朝向或現場存在證明。

## 現有資料的能力邊界

正式站圖是 89 個設施點與 19 條樓層連接關係，**不是已現地驗證的完整步行 Graph**。本輪只提供 zone／connector overview：

- 不捏造同樓層走廊邊，不計算不存在的距離／最快路線／轉彎方向，不承諾未知區域可達。
- 只採 `direction: bidirectional`、端點／樓層／zone 符合的連結；排除 `inferred`、`unverified`。
- 無階梯只採 `type: elevator` 且 `wheelchairAccessible: true`，再排除本次不可用設備；混合樓梯／電扶梯不符合無階梯限制。
- 同 zone 只代表同區域，不代表抵達，也不提供未經證實的走廊指示。
- 完整的「最快／最易懂」逐步導航仍需要實際走廊、轉彎、地標、可及性、設備可用性及現地核對；不以合成 demo 通過當正式北車路線已驗收。
- 真實集合等候區尚無 approved whitelist；不擅自把每個設施點都變成合法、安全的集合等候區。現有合成分享卡不推測映射到正式點。

## QR 契約

沿用獨立 preview namespace，與合成路網分開：

```json
{"type":"taipei_maze_anchor","v":1,"site_id":"taipei-main-map-preview","graph_major":1,"anchor_id":"station_b1-e4"}
```

station_ 後方為本地穩定 point ID；最多 1024 UTF-8 bytes，不帶 URL、座標、樓層或導航文字，僅接受本地存在且未停用的點。這些碼尚未現地布設／核准，正式場域仍需設置授權、資料核對與巡檢。

## 產生、預覽、下載與列印 QR

產碼工具沿用已登錄的 Lincoln Loop python-qrcode 8.2（BSD-3-Clause、固定 wheel hash），只用於建置，沒有新增 Web／手機依賴或線上 QR 服務。

```bash
python3 -m venv .local/qr-tools
.local/qr-tools/bin/python -m pip --isolated install --no-user \
  --index-url https://pypi.org/simple --require-hashes --no-deps \
  -r tools/requirements/station-qr.txt
.local/qr-tools/bin/python tools/generate-station-qr.py
```

輸出至 Git 忽略的 `.local/station-qr/`：

- index.html：按樓層與點位順序排列的預覽／列印表，提供單張 SVG、全部 ZIP 及對照 JSON 下載連結。
- 89 個 SVG：QR 使用與執行端相同的 stationQrPayload 函式產生。
- catalog.json：點位 ID、樓層、名稱及原始 payload 對照。
- station-qr.zip：包含列印表、對照 JSON 與全部 SVG。

開啟 index.html，可直接列印整份，或下載 ZIP 移交；產物不自動提交 repo 或上傳部署站。
