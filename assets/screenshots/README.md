# Application screenshots

We capture the running production website with Microsoft Playwright and a separate Google Chrome session. These PNGs show actual application states reached through navigation, search, checkboxes, step controls, dialogs and display preferences. We do not generate, retouch or replace application content.

- Mobile viewport: 430 × 932 CSS pixels, device scale factor 2.
- Wide-screen viewport: 1440 × 1000 CSS pixels.
- Endpoint/options and information captures use the browser's screenshot clip region to show complete relevant sections.
- We use reduced-motion preferences and disable capture-time animation to avoid transient frames.
- These are browser captures, not physical Android/iPhone WebView or field-validation records.
- Source revision, URL, browser and layout metrics are recorded in `manifest.json`; file integrity is recorded in `sha256.json`.
